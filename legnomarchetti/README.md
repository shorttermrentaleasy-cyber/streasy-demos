# Glamping Builder System

Demo del sistema commerciale digitale per costruttori di glamping.

## Struttura

- `/legnomarchetti/` - Landing di presentazione del sistema
- `/legnomarchetti/builder/` - Vista per il costruttore (configuratore, CRM demo)
- `/legnomarchetti/guest/` - Vista per il cliente finale (sito glamping chiavi in mano)

## Obiettivo

Mostrare ai costruttori di glamping come un sistema digitale può:

- Qualificare i contatti prima del preventivo
- Accelerare il processo commerciale
- Aumentare il valore percepito dell'offerta
- Offrire un pacchetto "struttura + avvio attività" al cliente finale

## Prossimi passi

- Creazione landing page
- Sviluppo configuratore
- Demo CRM
- Vista cliente finale
